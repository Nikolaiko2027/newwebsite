# Я буду делать сайт

Всем привет! Я делаю свой первый сайт на **FastAPI** — это простой и быстрый подход к веб-разработке.

## Что умеет сайт

- Показывает главную страницу
- Принимает имя через форму
- Отвечает персональным приветствием

## Как запустить сайт

1. Установи зависимости:

   ```
   pip install -r requirements.txt
   ```

2. Запусти сервер:

   ```
   uvicorn main:app --reload
   ```

3. Открой в браузере: http://127.0.0.1:8000

## Список файлов

- `index.html` — главная страница
- `main.py` — FastAPI-приложение
- `requirements.txt` — зависимости
